## 集め方

1. 観点の候補: search_patents で `fterm_cat:テーマ`（日本公開特許公報＋日本登録特許公報）を検索し、`fterm_asp` を上位 50 件まで集計した。50 件の枠は他テーマの観点と取り合うため、件数の少ない観点が漏れうる。
2. 漏れの確認: 各テーマで観点記号 AA〜ZZ の 676 通りすべてについて「テーマ＋記号＋00」を explain_patent_classifications で照会し、found=true のものを観点とした。
3. コード: 各観点の 01〜99 をすべて照会し、found=true のものだけを残した。

## 注意点

- 集計（fterm_asp）には出たが定義が見つからない観点は入れていない（いずれも 00 と 01 が found=false。旧観点の可能性があるが未検証）: 5H029 AS・CC、5F045 BA・EA・FA・GA、5F083 AA・BB・CC・CD・FF・HH。
- 集計の上位 50 件には出ず、全数照会で見つかった観点: 5H031 MM、5H043 CB、5F045 DB・DC・EJ・GH、5F083 CR。
- 番号は連続しない。5F045 の DA と DC は 01〜50 が無く 51 から始まる。5F157 は多くの観点で 90 番台まで使われる。
- 5F157 の BC・BD・BE・BF は観点名がどれも「洗浄液成分による洗浄」で返ってきた（戻り値のまま記載）。
- 5H029 と 5H028 はテーマ名がどちらも「二次電池」、5H030 と 5H031 はどちらも「二次電池の保守」で返ってきた。
- 観点名の末尾の「*」「◎」、「ゲ-ト」の「-」なども戻り値のまま。
