## 2. 設計方針

1. **上位型は P／M／U の 3 つだけ**にした。特許の【課題】は「耐水性に優れた〜を提供する」のように望む性質として書かれることが多く、効果（E）を別に立てると課題と効果が同じ語を取り合うため。材料・物質（T）も立てず、代表的な MOF 名は解決手段（材料）として M に入れた（依頼どおり）。
2. **上位型だけを共有すると類似度 0** になる計算なので、「同じ種類の課題・手段・用途」を中間概念でまとめた。深さは上位型=1、中間=2、小分類=3、葉=3〜4。
   - 同じ中間概念の直下の兄弟（深さ 3 どうし）: 2×2/(3+3) = 0.667
   - 小分類の下の兄弟（深さ 4 どうし）: 2×3/(4+4) = 0.75。いとこ（同じ中間概念で小分類が別）: 0.5
3. **複数の親は、深さが同じ親どうしに限った**。`_min_depth` が最小の深さを採るため、深さの違う親を持たせると「子と浅い側の親」の類似度が 1.0 になってしまう。例えば UiO-66 に「ジルコニウム」を親として足すと、UiO-66 とジルコニウムが同一扱い（1.0）になる。そのため MOF 名には金属種・配位子を親として付けていない（6 章の限界 3）。
   - 例外として横断的な中間概念を 2 つ置いた: 「水素の利用（横断）」（水素貯蔵・水素精製・燃料電池）と「二酸化炭素の回収・利用（横断）」（二酸化炭素回収・二酸化炭素の変換）。どちらも親は深さ 2 どうし。
4. **表層形は最長一致で拾われる**（`surface_forms` は葉と、別名を持つ中間概念が対象）。この仕組みに合わせて次のようにした。
   - 1〜2 文字の英字の別名は入れない（Zr、Cu、K+ などは除外）。3 文字の略語は、MOF 特許で意味が決まるもの（BDC、BTC、ZIF、VOC、DAC、PSA、MMM など）に限った。HER・ANG は英単語の一部に当たるため外した。
   - 英数字を含む別名は、**全角英数字とハイフン違い（− U+2212、－ U+FF0D、‐ U+2010）の表記を機械的に足した**。Summaria の要約は「ＭＯＦ−７４」「ＣＯ<sub>２</sub>」のような全角表記で、ontomap は本文を正規化しないため。
   - 「金属有機構造体」「多孔性配位高分子」「多孔性金属錯体」「有機配位子」「金属イオン」のように**ほぼ全文書に出る語は、わざと概念にしていない**。入れても全文書が同じように近くなるだけで、文書を区別する手がかりにならないため。
   - 長い語が短い語を飲み込む誤一致は、より長い表記を別の概念に登録して防いだ。例: 「芳香環」が「芳香」（用途の芳香材）に当たらないよう、芳香材の別名から「芳香」単独を外した。「多孔性配位高分子複合体」の中の「高分子複合」、「多孔性配位高分子触媒」の中の「分子触媒」、「多孔性金属錯体」の中の「金属錯体」は別名から外した。
5. **略語は日本語名を preferred label にした**。例: 揮発性有機化合物（VOC）、混合マトリクス膜（MMM）、合成後修飾（PSM）、薬物送達（DDS）。日本語名のない MOF 名（ZIF-8、UiO-66 など）は名前をそのまま label にした。

## 3. 上位型と中間概念

括弧内は概念 ID。中間概念の下に並べたのは葉の概念。

- **課題**（P）
  - **安定性の課題**（P_stability）: 耐水性、熱安定性、化学的安定性、骨格の崩壊、繰り返し耐久性
  - **吸着性能の課題**（P_adsorption）: 吸着選択性、吸脱着速度、再生エネルギー、吸脱着ヒステリシス、低圧域での吸着、吸脱着特性
    - **吸着量**（P_capacity）: 有効吸着量
  - **包接・放出の課題**（P_guest）: 担持量、徐放性、担持物の脱落、送達性能
  - **装置・運転の課題**（P_device）: 装置の小型化、吸着熱・反応熱による温度上昇、伝熱性、安全性、操作性
  - **汚染・ガス発生の課題**（P_contamination）: ガスの発生、腐食・変色
  - **製造の課題**（P_production）: 収率、製造コスト、量産性、溶媒の負荷、合成時間、結晶形態の制御、純度、再現性
  - **成形・加工の課題**（P_processing）: 粉体の取扱い、成形体の強度、膜化、分散性、硬化性、成形による性能低下
  - **機能性能の課題**（P_function）
    - **電子・光機能の課題**（P_electronic）: 導電性、イオン伝導性、発光特性、電池性能、誘電特性
    - **触媒性能の課題**（P_catalytic）: 触媒活性、反応選択性、触媒寿命
    - **検知性能の課題**（P_sensing）: 検知感度
- **解決手段**（M）
  - **金属種の選択**（M_metal）: ビスマス、金属クラスター、異種金属の併用
    - 典型金属（M_metal_main）: マグネシウム、アルミニウム、カルシウム、アルカリ金属イオン
    - 遷移金属（M_metal_tm）: 銅イオン、亜鉛、鉄イオン、クロム、コバルト、ニッケル、マンガン
    - 第４族金属（M_metal_g4）: ジルコニウム、チタン、ハフニウム
    - 希土類金属（M_metal_re）: ランタノイドイオン
  - **有機配位子の設計**（M_ligand）: シアノ架橋配位子、混合配位子、ポルフィリン
    - カルボン酸系配位子（M_lig_carbox）: テレフタル酸、トリメシン酸、ジヒドロキシテレフタル酸、フマル酸、ビフェニルジカルボン酸、ナフタレンジカルボン酸、アセチレンジカルボン酸、イソフタル酸
    - アゾール系配位子（M_lig_azole）: イミダゾール系、トリアゾール系、ピラゾール系
    - 含窒素中性配位子（M_lig_neutral）: ピラジン、ビピリジン、ジアザビシクロオクタン
    - 官能基の付与（M_lig_func）: アミノ基、水酸基、スルホン酸基、アミド基、含フッ素配位子、ニトロ基、光反応性部位、ヒドリド供与基
    - 生体由来配位子（M_lig_bio）: シクロデキストリン、アミノ酸配位子
  - **骨格・細孔設計**（M_framework）: 細孔径の制御、配位不飽和金属サイト、欠陥導入、柔軟構造、相互貫入構造、結晶構造の特定、非晶質化、層状構造、細孔表面の化学修飾
  - **合成法**（M_synthesis）: ソルボサーマル合成、水系合成、温和条件合成、機械化学合成、連続フロー合成、マイクロ波合成、超音波合成、噴霧乾燥合成、電気化学合成、モジュレーター、原料の選択、原料の分散処理、結晶化条件の制御
  - **後処理・後修飾**（M_postproc）: 活性化処理、超臨界二酸化炭素処理、合成後修飾（PSM）、アミン修飾、ゲスト分子の含浸、熱処理・炭化
  - **複合化**（M_composite）: 混合マトリクス膜（MMM）、コアシェル構造、金属ナノ粒子複合、イオン液体複合、配位高分子による被覆、高分子複合、金属錯体の導入
    - 担体への担持（M_support）: セルロース複合、繊維担持、炭素材料複合、無機担体
  - **成形**（M_forming）: ペレット・顆粒成形、薄膜形成、バインダー、シート化、モノリス・エアロゲル、粒子形態の制御
  - **装置・プロセス構成**（M_system）: 吸着塔、脱着・再生操作、電気分解の併用、フィルタの配置、運転条件の制御、被処理ガスの導入
  - **計算・機械学習による設計**（M_computational）: 機械学習モデル、分子シミュレーション
  - **代表的なMOF**（M_named_mof）: HKUST系（HKUST-1）、IRMOF系（MOF-5、その他のIRMOF）、ゼオライト様イミダゾレート骨格体（ZIF-8、ZIF-67、その他のZIF）、UiO系（UiO-66、UiO-67、その他のZr系MOF）、MIL系（MIL-101、MIL-100、MIL-53類、その他のMIL・CAU系）、MOF-74系（MOF-74）、フマル酸アルミニウム系（フマル酸アルミニウム、MOF-303）、ピラードレイヤー型PCP（CPL-1、ELM-11、SIFSIX-3）、シアノ架橋型配位高分子（プルシアンブルー類似体、ホフマン型錯体）、導電性MOF（Cu3(HHTP)2）
- **用途**（U）: 熱管理材料、移動体用途（この 2 つは上位型の直下の葉）
  - **ガス貯蔵**（U_gas_storage）: 水素貯蔵、メタン貯蔵、アセチレン貯蔵、酸素貯蔵、ガス供給システム
  - **ガス分離**（U_gas_sep）: 二酸化炭素回収（その下に大気中二酸化炭素の直接回収）、炭化水素分離、含フッ素化合物の分離、希ガス分離、水素精製、空気分離、排気ガスの回収、分離膜
  - **触媒**（U_catalysis）: 光触媒、電極触媒、二酸化炭素の変換、アンモニア合成・分解、重合触媒、有機合成触媒
  - **センサ**（U_sensor）: ガスセンサ、化学センサ、蛍光センサ
  - **電気化学デバイス**（U_electrochem）: 二次電池、固体電解質、キャパシタ、燃料電池、太陽電池
  - **電子デバイス**（U_electronics）: 絶縁膜、その他の機能デバイス
  - **水吸着**（U_water_ads）: 除湿、吸着式ヒートポンプ、大気水回収
  - **有害物質の除去**（U_removal）: 揮発性有機化合物（VOC）の除去、消臭、水処理、重金属の除去、脱硫、有毒ガスの除去、抗菌・抗ウイルス
  - **医薬用途**（U_medical）: 薬物送達（DDS）、造影・診断、化粧品
  - **機能性物質の放出**（U_release_use）: 芳香材、防虫・農業、食品・鮮度保持
  - **光学・発光材料**（U_optical）: 発光材料、非線形光学材料
  - **塗料・樹脂・接着の用途**（U_coating_use）: 塗料、接着剤、樹脂添加剤
  - 横断: **水素の利用（横断）**（U_hydrogen）= 水素貯蔵・水素精製・燃料電池、**二酸化炭素の回収・利用（横断）**（U_co2_chain）= 二酸化炭素回収・二酸化炭素の変換

## 4. 述語の定義

`predicate_sim` は、同じ述語=1、同じ group=0.7、polarity が逆=0、それ以外=0.2。

| ID | 意味（始点→終点） | group | polarity |
|---|---|---|---|
| addresses | 手段が課題を解決する（手段→課題） | reduce | -1 |
| suppresses | 抑制する（手段→課題）。辞書抽出器が出す述語との互換用 | reduce | -1 |
| prevents | 防止する（手段→課題）。同上 | reduce | -1 |
| causes | 手段が課題を引き起こす（副作用。例: 混合配位子→副生成物） | induce | +1 |
| degrades | 課題が手段を劣化させる。辞書抽出器との互換用 | induce | +1 |
| used_for | 手段・材料が用途に使われる（手段→用途） | apply | 0 |
| applied_to | 適用される（手段→用途）。辞書抽出器との互換用 | apply | 0 |
| arises_in | 課題が用途で問題になる（課題→用途） | locate | 0 |
| occurs_in | 生じる場所（課題→用途）。辞書抽出器との互換用 | locate | 0 |
| composed_of | 材料が金属種・配位子・構造を構成要素として持つ（手段→手段） | compose | 0 |
| made_by | 材料・成形体が合成法・後処理で作られる（手段→手段） | make | 0 |

`config/experiment.yaml` の `predicate_weights` は suppresses / prevents / causes / degrades / occurs_in / applied_to を参照しているので、互換用の述語を残した。addresses / used_for / arises_in / composed_of / made_by は `predicate_weights` に無いため、比較コード側で重みを決める必要がある。

## 6. 既知の限界

1. **数値は楽観側に偏っている。** 語彙を、同じ 200 件で拾えなかった文書（課題 37 件、用途 33 件）を見て足した。別の文書群での検証はしていない。
2. **列挙と文脈を区別しない。** 最長一致は文脈を見ないので、請求項や実施形態の列挙（「亜鉛、銅、マグネシウム、アルミニウム、…からなる群」「ジカルボン酸、トリカルボン酸、…」）がすべて解決手段として数えられる。解決手段の平均 6.33 種類のかなりの部分は列挙から来ている。先行技術の説明（「ゼオライトや活性炭など」）も同じように拾われるため、「ゼオライト」「活性炭」単独は別名から外した。
3. **MOF 名と構成要素の近さが 0。** UiO-66 とジルコニウム、ZIF-8 とイミダゾール系配位子は、上位型（解決手段）しか共有しないので類似度 0。2 章 3 の理由で親として足せない。三つ組 `UiO-66 composed_of ジルコニウム` で表すか、比較コード側で補う必要がある。
4. **辞書抽出器（`ontomap/extract/dictionary.py`）とのかみ合わせ。** 抽出規則は上位型 T / A / E を前提にした部分（performs、leads_to、applied_to は T が要る）があり、このオントロジーには T / A / E が無い。そのため辞書抽出器から出るのは主に suppresses / prevents（手段→課題）、causes、degrades で、used_for / arises_in（用途への関係）は出ない。用途との関係を三つ組で比べるなら、LLM 抽出か比較コード側の規則が要る。`TOP_TO_ROLE` には U=用途 があるので、概念の出現と役割の付与はそのまま動く。
5. **本文の正規化をしていない前提で作った。** 全角・半角とハイフン違いは別名で補ったが、ほかの表記ゆれ（全角スペース入り、上付き・下付きタグ入りの化学式、例えば「Ｈ<sub>２</sub>Ｏ」「Ｍｇ<sub>２</sub>（ｄｏｂｄｃ）」）は拾えない。比較コード側で NFKC 正規化とタグ除去をすると取りこぼしが減る（その場合、全角の別名は使われなくなるだけで害はない）。
6. **1 文字の金属名は拾わない。** 「銅」「鉄」「銀」単独は誤一致が多いので、「銅イオン」「鉄イオン」「銅塩」のような形だけを登録した。列挙の中の「銅」は拾われない。
