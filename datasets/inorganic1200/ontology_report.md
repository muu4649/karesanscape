## 1. 作り方

1. **入力**: `datasets/inorganic1200/documents_sections.csv`（1,200 件、5 分野 × 240 件）だけを使った。読み込みは `ontomap.patents.data.load_patent_csv`。抽出側と同じく NFKC で正規化し、段落番号を除いている。
2. **分割**: doc_id の番号が奇数の 600 件を開発用、偶数の 600 件を確認用にした。分野ごとに 120 件ずつになる。
3. **候補語の抽出（開発用だけ）**: janome で課題・解決手段・用途の段落ごとに名詞の連なりを取り、1〜4 形態素の部分列を数えた。数えたのは段落ごとの文書頻度と、ほかの 2 つの段落に比べた偏り（出現率の対数比）。
4. **階層と別名を人が決める**: 候補語の表と一般的な材料化学の知識をもとに、上位型 → 中間概念 → 末端概念の 3 段の木を作った。木はスクリプト内の `TREE` にデータとして持つ。
5. **開発用で直す（3 回）**:
   - (a) 上位型が 0 件だった段落を読み、本文にある言い方を足した。
   - (b) 表記ごとの出現数を見て、長い語の一部に当たった誤一致と、意味の薄い汎用語を消した。主なもの:
     - 「におい」が「において」に当たっていた
     - 「スス」が「ステンレス」に、「NO2」が「SnO2」に、「Li2S」が「Li2SO4」に当たっていた
     - 「エチレン」「グリコール」が「ポリエチレングリコール」に、「ニトリル」が「ベンゾニトリル」に当たっていた
     - 汎用語として「粒子」「混合物」「加熱」「組成」「困難」などを消した
   - (c) 長い語を別の概念に入れて、短い語の誤一致を止めた（例: スチレンブタジエンゴム → バインダー、プロピレンカーボネート → 電解液、水銀圧入 → 細孔構造）。
6. **書き出しの決まり**:
   - ハイフンを含む別名には、`-` `−` `‐` の 3 通りとハイフン無しを自動で足す（本文に `−`（U+2212）が 2,952 回、`-` が 2,781 回、`‐` が 138 回あったため）。
   - 1〜2 文字の英数字の別名は、スクリプトがエラーにして入れない。
   - 同じ表記が 2 つの概念に入ったときも、スクリプトがエラーにする。
7. **版の固定**: YAML の先頭のコメントに、固定日（2026-10-19）と内容のハッシュを書いた。

## 3. 述語の定義

`predicate_sim` の決まり: 同じ述語は 1、同じ group は 0.7、polarity の積が負なら 0、それ以外は 0.2。

| ID | 意味 | group | polarity |
|---|---|---|---|
| addresses | 手段（M）が課題（P）を解決する | reduce | -1 |
| used_for | 手段（M）が用途（U）に使われる | apply | 0 |
| arises_in | 課題（P）が用途（U）で問題になる | locate | 0 |
| suppresses / prevents | 抑制する・防止する（互換用） | reduce | -1 |
| causes / degrades | 引き起こす・劣化させる（互換用） | induce | +1 |
| applied_to / occurs_in | 適用先・生じる場所（互換用） | locate | 0 |

新しい述語は足していない。

## 6. 既知の限界

- **課題段落の表現**: 発明の内容を言い直すだけで課題を書かない課題段落が多い（例: 「〜の製造方法を提供する」）。こうした段落では、P は拾えない。
- **用途段落の抽出**: 用途段落の 0 件率が 24〜26% と高い。用途段落の多くは、収集時に「用い」「使用」を含む段落を選んだもので、用途を述べていない（定義・製法・材料の列挙）。改善するなら、語の追加よりも段落の取り方を直すほうが効く。
- **汎用語**: 汎用的な概念が残っている（新規な、生産性、コスト、耐久性、品質、担持、焼成など）。拾えた件数の上位は、生産性・コスト・煩雑といった汎用の課題で占められる。比較実験で、こうした概念の一致が類似度を水増しするおそれがある。「新規な」（P_novelty）は情報が少ないので、必要なら比較から外すこと。
- **類似度の段階**: 階層は 3 段で、親は 1 つ。類似度は兄弟の 0.667 と 0 の 2 段階しかなく、中間概念をまたぐ近さ（例: ゼオライト膜と分離膜、触媒活性と失活の関係）は表せない。
- **型の取り違え**: 同じ語が文脈で役割を変える場合に、片方の型に固定している。
  - 「炭化水素」は U（石油精製）に入れたが、排ガスの文脈では汚染物質。
  - 「セシウム」は P（放射性）に入れたが、触媒では助触媒。
  - 「吸着剤」「フィルター」は U に入れたが、材料そのものを指すこともある。
  - 「比表面積」「細孔径」は M（構造の規定）に入れた。課題段落に出ても P にはならない（「高比表面積」などの言い方だけ P に入れた）。
- **部分一致**: 部分一致による誤一致が残る可能性がある。開発用で見つけたものは消したが、確認用は調べていない。
- **ZIF-8 の扱い**: 無機材料の本文には出てくるが、多孔質骨格材料の末端概念は 1 つだけなので、ZIF-8 は「金属有機構造体」1 概念にまとまっている。MOF の名称の細分（ZIF 系・カルボン酸系など）は持たない。そのため MOF 文書どうしの比較では、材料名による区別はつかない。
- **網羅の限界**: 別名は開発用 600 件と一般知識に依存しており、MOF 特許に特有の課題・用途の言い方（例: 吸着熱、ゲート吸着、ガス貯蔵密度）は網羅していないとみられる。これは意図した制約で、評価の甘さを避けるための代償。
