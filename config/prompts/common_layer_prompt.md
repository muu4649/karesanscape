## 辞書の決まり
- 型は 3 つです。
  - 課題: 発明が解決しようとする問題や、良くしたい性能（例: サイクル特性、内部短絡、膜厚の均一性、コスト）
  - 解決手段: 材料・構造・製法・装置・条件など、課題を解くための手段（例: 固体電解質、セパレータ、原子層堆積、焼成）
  - 用途: 発明が使われる製品・機器・場面（例: 電気自動車、半導体メモリ、排ガス浄化）
- 型ごとに「中間概念」（まとまり）を 5〜12 個作り、その下に「概念」を置いてください。概念は全体で {{N_CONCEPTS}} 個くらいにしてください。
- 概念には「別名」を 3〜10 個付けてください。別名は、日本の特許明細書に実際に出る書き方にします。
  - 表記ゆれ（例: セパレータ、セパレーター）、言い換え（例: 内部短絡、短絡）、略語と英語（例: 原子層堆積、ALD）、よく使う複合語（例: 正極活物質層）
  - 「〜の向上」「〜を抑制」のような言い回しは付けず、名詞だけにする（例: 「サイクル特性の向上」ではなく「サイクル特性」）
  - 本文によく出る素朴な呼び方も、いちばん近い概念の別名に入れる（例: 「電池」「二次電池」「半導体装置」「基板」）。特許の用途の段落は「本発明の〇〇は、△△に用いることができる」のような短い書き方が多いため
- 用途は製品だけでなく、「〜用」「〜に用いる」の相手になる機器・部材・場面も入れてください（例: 車載用電源、蓄電装置、表示装置の画素）
- 次のものは入れないでください。
  - どの分野にも出る意味の薄い語（例: 構造、方法、材料、装置、表面、形状、性能）
  - 1〜2 文字の英数字だけの別名（例: Si、Al、CO）。長い語の一部に誤って当たるためです。3 文字以上ならよい（例: ALD、SiC）
  - 同じ別名を 2 つの概念に入れること

CSV だけを、1 つのコードブロックで出してください。説明の文は要りません。1 行目は次の見出しです。

```
型,分野,中間概念,概念,別名
```

- 型: 「課題」「解決手段」「用途」のどれか
- 分野: {{MODULE_RULE}}
- 中間概念: まとまりの名前（同じまとまりの行は同じ名前にする）
- 概念: 本文に出る言い方の名前
- 別名: 「|」で区切る（例: セパレータ|セパレーター|隔離膜）
- 値にカンマが入るときは、値全体を "" で囲む
